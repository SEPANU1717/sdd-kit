# Checklist

Read the constitution, spec, relevant decisions, and repository evidence. Use
`.agents/templates/checklist.md`. Check ambiguity, scope, observable behavior,
edge cases, non-functional requirements, traceability, and testability.

Do not change product decisions or implementation. Report findings and route
decisions back through clarify/specify. A checklist is a quality gate, not an
approval shortcut.
