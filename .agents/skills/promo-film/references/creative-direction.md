# Creative direction

## What makes a promo good

1. **A hook on frame 0.** Something moves on frame 0, and the product does
   something within about 1.5 s. Use one of these:
   - *Mark opens into the product.* The logo sits centred, a cursor glides in and
     clicks it, and the logo opens into the product's main UI (the Sepadial
     dial opens into the wheel). This doubles as the loop point.
   - *Old way vs one move.* A fast, cluttered "7 clicks" montage freezes, then
     the clean product does it in one move. Use it when the pain is well known.
   - *Camera reveal.* Start close on the brand inside the real window and pull
     back to the whole window as a cursor clicks. A confident move, but it only
     shows the brand, so pair it with a feature right after.
2. **The word does the feature.** Each section gets one lowercase verb or noun
   with an accent full stop ("crop.", "blur.", "yours."). The picture under it
   shows that exact thing happening.
3. **One hero object.** Pick the product's signature UI (a wheel, a command bar,
   an editor window). It stays on screen across scenes: it shrinks to a
   progress ring, flies into the result, reopens with new settings.
   Neighbouring scenes share one window card whose content crossfades
   (image editor → video editor).
4. **Repeat a mechanic on the beat.** One control changes per beat while the
   hero stays still: accent swatch, roundness slider, gap slider, dark tiles.
   This is how you show configuration.
5. **Real context.** Show the product where it's used (File Explorer, the
   desktop), drawn in the film's own card style so it stays consistent.
6. **A trust beat near the end.** One big word ("offline.", "private.") and a
   single quiet visual, with the music stripped back.
7. **A lockup that pays off the hook.** Logo → name → tagline, one word per beat.
   For a loop, fold back into frame 0.

## Avoid

- Full app shells with tiny text (dashboards sell nothing)
- Features shown as small tilted cards or cropped tiles
- More than about 2 s of logo on an empty background
- Several accent colours, mixed card styles, or a different word position per scene
- Copying a reference's layout. Take its techniques, not its frames.

## Structure (30 s at 124 BPM: 62 beats, plus 3 for a hook and 1 for a loop fold)

| Beats | Chapter | Example words |
| --- | --- | --- |
| 0–3 | Hook | one wheel. |
| 3–15 | Core action | drag. hold. pick. done. |
| 15–23 | Make it yours (configuration) | yours. |
| 23–38 | Feature group A, 3 beats per verb | crop. erase. blur. mark up. beautify. |
| 38–48 | Feature group B | video. (the caption changes every ~3 beats) |
| 48–54 | Everything else, 4 panels | and more. |
| 54–58 | Trust | offline. |
| 58–66 | Lockup (+ loop fold) | Drag. Pick. Done. |
